A seller follow started by adding to the cart or watchlist, checking out, following a shop, making an offer or placing a bid now stops when the buyer signs out, as the one started from a chat message already did. A watchlist check that was still running at sign-out starts no new listing check and saves nothing, a retried review removal sends nothing more for the account that left, and a profile or feed refresh that starts while another account signs in over the current one, or while sign-out is still clearing the account, no longer saves the previous account's view into the device. A review removed just as the account signed out, whose public copy was left behind, is now deleted the next time that account opens the order on a device that no longer has the review stored, once the service confirms the removal and the 24-hour review edit window has closed, so an edit made on another device is never deleted. A review published under the old per-listing path is deleted the same way while it still carries that order's purchase attestation, and is left in place once another order's review has replaced it. A retried review removal that hits a temporary homeserver error is retried the next time the orders load, not after the account has left.
