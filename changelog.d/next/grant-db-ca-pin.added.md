The Shop server can verify its grant-state database's TLS certificate. Set `SHOP_BFF_GRANT_STATE_DATABASE_CA_PEM` to the database's CA certificates, including the root CA, and `SHOP_BFF_GRANT_STATE_DATABASE_TLS_SERVER_NAME` when the server certificate names a host other than the one in the database URL (`localhost` on Railway); a mismatch refuses the connection. With neither set, the connection behaves as before.
