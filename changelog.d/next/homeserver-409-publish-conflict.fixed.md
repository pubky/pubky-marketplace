A save no longer fails when a homeserver on Google Cloud Storage answers 409 "read it again and retry" (a late write it refused to publish over). The Shop retries such a write with the usual backoff; a listing publish reads the listing again first, so an edit that landed in between is reported as a conflict instead of being overwritten. A real 409, such as a file/folder path collision, still fails at once. Listing publishes and deletes also retry 429, 500 and 503 again, as intended.
