The agent guide at `/llms.txt` builds its reputation query from the same trust windows the Shop uses: a key's window ends early when a trusted attestor's verified signed profile sets an earlier end or compromise time, and the guide shows the configured bound beside it. When any attestor profile is unread, unverified, still being read again or last failed to read, the guide marks every configured key window as unconfirmed, because a profile can end the window of any configured key and not only its own. It names each such profile with how to apply its cutoff, and treats counts from the configured bounds as upper bounds and ratings as unconfirmed. When a profile that the Shop verified with a cutoff later answers 404, the Shop keeps the cutoff, and the guide marks every window unconfirmed and explains that a server that never saw the profile applies the configured windows. Without the index's scoped figure, the guide merges a key's touching or overlapping windows before testing whether one covers a bucket, as the Shop does, and keeps windows separated by a gap distinct. For reviews served without an attestation time, it explains the `created_at` fallback window by window: a bounded window never counts them, and only an open-ended window does. It reports a seller rating only when seller-rated buyers exist.
