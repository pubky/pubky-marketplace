The agent guide at `/llms.txt` builds its reputation query from the same trust windows the Shop uses: a key's window ends early when a trusted attestor's verified signed profile sets an earlier end or compromise time, and the guide shows the configured bound beside it. When a profile cannot be read or verified, the guide says so for that attestor, explains how to apply its cutoff, and treats counts from the configured bounds as upper bounds and ratings as unconfirmed. It reports a seller rating only when seller-rated buyers exist, and explains how reviews served without an attestation time are counted.
