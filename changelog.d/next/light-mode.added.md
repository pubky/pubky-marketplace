The shop now follows the Pubky theme: it reads the `pubky-theme` preference pubky-app saves (Dark, Light or System, where System follows the device), applies it before first paint, and switches live when it changes in pubky-app or on the device. Light mode uses the same grey page, white cards, logo and background artwork, and Pastel tag colours as pubky-app, with darker brand and secondary text so it meets WCAG AA contrast. Dark mode is unchanged.
