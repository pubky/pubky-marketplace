Store mode: `PUBKY_RUNTIME_STORE_SELLER` runs the Shop as one seller's store. `/` opens that seller's shop; other sellers' pages, global browse and search, the social pages, the hosted Market's support and agent endpoints and files the app does not ship return 404, and only the store seller sees and can open the selling tools. Every other signed-in user keeps only its buyer side there, in orders, offers, reviews, notifications and messages, in sandbox and live commerce modes alike. A store is never embedded or framed. A store opened over plain HTTP shows how to open it over HTTPS instead of a sign-in that cannot finish. Unset, the Shop is unchanged.
