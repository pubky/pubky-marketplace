Store mode: `PUBKY_RUNTIME_STORE_SELLER` runs the Shop as one seller's store. `/` opens that seller's shop; other sellers' pages, global browse and search, the social pages and the hosted Market's support and agent endpoints return 404, and only the store seller can open the selling tools. A store is never embedded or framed. A store opened over plain HTTP shows how to open it over HTTPS instead of a sign-in that cannot finish. Unset, the Shop is unchanged.
