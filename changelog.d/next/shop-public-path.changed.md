Launch tooling for the Shop's new home at `https://pubky.app/shop`, where the App owns `/shop` as a same-origin iframe wrapper and the Shop build runs at `NEXT_PUBLIC_BASE_PATH=/shop-embed`. New runtime setting `PUBKY_RUNTIME_SHOP_PUBLIC_PATH=/shop` points share links, report links, canonical and Open Graph URLs at the App's `/shop`, while assets, API calls and the Passport popup return stay on `/shop-embed`. The launch-critical suite takes the build's mount path on `LAUNCH_E2E_BASE_URL`. Install verification gains `SHOP_EMBED_PATH` (the wrapper must load, the framed build must load and allow a same-origin frame, and publish the public path) and `SERVICE_PUBLIC_APP_ORIGIN` (PayPal return and cancel must land on `/shop`, not `/shop-embed`). A standalone Shop is unchanged. See `docs/launch/shop-embedding.md`.
