Sellers can import a WooCommerce store by pasting its address in Studio's import ("From a WooCommerce store URL"), with no API keys. The Shop reads the store's public product list, shows the same dry run as a file import with a loss report, and loads the photos on publish. Prices keep the store's currency. A product's stock is its cart limit when the store has one, otherwise the default quantity you choose, and each item that used a cart limit or a default is listed in the report.
