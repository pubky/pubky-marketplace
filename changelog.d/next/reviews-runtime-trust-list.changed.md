The review attestor trust list is now runtime config. Each deployment lists its transaction service's attestor in `PUBKY_RUNTIME_MARKETPLACE_TRUSTED_ATTESTORS` as `{pubky, label, validFrom, validUntil?}` entries, and the build no longer compiles in any deployment's keys. A review counts as a verified purchase only when its attestation falls inside its attestor's window, and the badge names the attestor ("Verified purchase · Pubky Market"). Public review lists cannot see when an attestation was signed yet, so there a key with an end date no longer vouches for any review. Set the variable before deploying this release, or every review shows "Attested (unrecognized attestor)".
