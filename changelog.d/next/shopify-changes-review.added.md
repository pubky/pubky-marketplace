Sellers with a connected Shopify store can let linked listings follow it. Store connections gets a Sync table (title, description and photos; price; variants) and a Shopify changes review: store text applies when the page opens, a product the store stops selling pauses its listing, and a price or variant change waits for a tap. A field the seller and the store both changed is a conflict with a choice. The listing editor shows the parts that follow the store read-only, with Edit in Shopify and a switch that overrides them for that listing. Off unless `PUBKY_RUNTIME_STORE_SYNC_ENABLED` is on.
