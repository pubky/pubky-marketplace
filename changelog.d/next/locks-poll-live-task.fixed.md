A Locks payment still waiting after its one-hour marketplace window, while the marketplace holds the order for the Lock Server's task, no longer shows a "Keep checking" button. Checkout and Orders keep reading the order while they are open, so a late confirmation shows as paid without a reload, and each pending payment no longer adds its own extra order reads. If cancelling is paused while a payment is still in progress, the Shop now says so instead of claiming a payment was seen. If the seller changed what a listing unlocks after checkout, the Shop no longer says the order can't be paid; it asks you to check the order's status and to cancel only if the order still offers that.
